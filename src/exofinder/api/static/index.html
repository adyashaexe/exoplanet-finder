Exoplanet Finder

Simulated 30-minute photometry with starspots, flares and gaps. Each draw is a new random star.

CSV or text with time, flux and optional flux_err columns, or a Kepler/TESS light curve FITS file. Up to 40 MB.

Downloads every available quarter or sector from NASA's MAST archive, so the server needs internet access. A full Kepler star can take a minute.
